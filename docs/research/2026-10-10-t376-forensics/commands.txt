## 3. `PRAGMA journal_mode=WAL` 撞并发写锁的最小实验（§4，纯标准库 sqlite3）

```python
import sqlite3, os, tempfile
os.makedirs("/tmp/t376exp", exist_ok=True)
p = os.path.join(tempfile.mkdtemp(dir="/tmp/t376exp"), "h.db")
a = sqlite3.connect(p); a.execute("CREATE TABLE t(x)"); a.commit()
# A：另一连接仅打开（无事务）
b = sqlite3.connect(p, timeout=5.0)
print("A:", b.execute("PRAGMA journal_mode=WAL").fetchone())   # A: ('wal',) —— 成功
b.close()
# B：另一连接持 BEGIN IMMEDIATE
a.execute("BEGIN IMMEDIATE")
c = sqlite3.connect(p, timeout=1.0)
try:
    print("B:", c.execute("PRAGMA journal_mode=WAL").fetchone())
except sqlite3.OperationalError as e:
    print("B BUSY:", e)                                        # B BUSY: database is locked
```
