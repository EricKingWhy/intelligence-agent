# ADR-0028 — 宿主只读目录浏览端点：Web 端目录选择器的唯一可行路径

**Status**: Accepted
**Date**: 2026-09-12
**Related**: ADR-0027（会话 `cwd`——本端点为其与 `POST /api/projects` 提供选目录的 UI 前提）、
ADR-0025（项目 = 任意已存在目录）、#155（AC3 明文"不做目录浏览器；若要做，单独立项，
且需新的宿主侧端点"——本 ADR 就是那张立项）、issue #170（WS-7）、grill 2026-09-12
（Q4 安全组合 / Q5 前端形态，用户拍板"听推荐"）
**Supersedes**: 无。

---

## Context

「新建项目」与「新目录开任务」都要求用户提供一个**真实的绝对路径**。在浏览器里只有三种
取路径的方式，前两种被平台安全模型直接排除：

1. `<input type="file" webkitdirectory>`：能选目录，但浏览器出于安全只回报
   `C:\fakepath\<名字>`——**没有真实绝对路径**。
2. File System Access API（`showDirectoryPicker()`，仅 Chromium）：能拿到目录句柄，但句柄
   **不暴露自身绝对路径**（只有 `.name`；规范里就没有获取完整路径的 API）。
3. **宿主侧列举端点**：后端与本机同进程部署（本地信任模式），由它列目录、前端自绘选择器。
   这是唯一能拿到真实绝对路径的路径——#155 AC3 当初预言的"需新的宿主侧端点"即此。

参考形态（用户截图）：桌面应用（ZCode）的原生"打开文件夹"对话框。Web 端无法调用原生对话框，
但可以用「后端列举 + 前端自绘」逼近同一体验。

## Decision

**D1 — 端点形态**：`GET /api/host/dirs?path=<可选>`。

- `path` 缺省 → 返回**盘符/根列表**（Windows：可用驱动器；POSIX：`/`）。
- `path` 给定 → 返回该目录的**直接子目录**（仅目录，不含文件；depth 恒为 1），每项含
  `name` 与 `path`（规范化绝对路径）。响应同时回显 `path` 的规范化结果与 `parent`（上一级，
  供"向上"导航；根的 parent 为 null）。
- 目录不存在 / 不是目录 / 无权限 → **4xx**（404 / 422 / 403），detail 说明原因——不许冒成 500。
- **条目上限**（500）：超限截断并在响应里标记 `truncated: true`（诚实降级，不静默）。
- **不跟随符号链接**展开为新遍历根：symlink 目录照实列出一个条目（点击进入时后端按真实目标
  解析，仍是普通的一层列举），不循环、不逃逸。
- 明确**不做**：读文件内容、通配/搜索、写操作、隐藏属性开关（隐藏目录照列，由前端排序置底）。

**D2 — 授权闸**：复用 `require_trusted_origin`（与项目/记忆端点同一份，**刻意不复制**——
安全规则两份副本就是两个漂移面）。本地信任模式 = 仅本机来源；JWT 模式 = 认证后可用。
不新增"仅回环"断言：trust 闸已表达同一意图，且 JWT 部署下回环断言反而是错的。

**D3 — 前端形态（Q5）**：「新建项目」对话框内嵌目录浏览器：当前路径条 + 子目录列表
（点选进入）+「选择此目录」确认；与既有**手填输入框双向同步**（粘贴路径回车 = 跳转浏览；
点选 = 回填输入框）。手填保留为完整后备路径。同一组件复用于「新目录开任务」的目录选择
（ADR-0027 的创建确认面）。

## Considered Alternatives

- **原生对话框**：浏览器不可得（见 Context）。否决。
- **File System Access API**：拿不到绝对路径，注册无从谈起；且 Firefox/Safari 不支持。否决。
- **不做端点，继续手填**：用户明确反馈"一点都不人性化"；且 ADR-0027 之后"选目录"成为
  高频动作。否决（手填保留为后备，不是主路径）。

## Security

- 只读、只列目录名与路径、depth=1、条目上限——信息泄露面 = "这台机器上有哪些目录"，
  与"本地信任模式下 UI 本就可以注册任意目录"的既有能力同阶。
- 端点**不接收任何写语义**；`path` 参数只被解析与列举，永不拼进 shell 或写路径。
- 列举遵循 OS 权限：无权限的目录返回 403 条目错误（整页 403），不降级成空列表伪装。

## Consequences

- `web/` 新增一个路由文件与一条测试；前端新增一个可复用的目录浏览器组件。
- 该端点是**信息面**新增：JWT 部署下它被认证保护；若未来部署形态变成"后端不在用户本机"，
  本端点必须随部署形态重新评估（在 ADR-0001 的 Host 边界语境里记录此约束）。
