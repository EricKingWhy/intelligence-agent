## 关联观察（据实记录，不在本批修）

1. **服务跨卸载/更新存活**：C 与 E 腿起始时，先前由 TUI 冷启动的服务（pid 7920）仍在运行，且它的可执行文件位于被替换过的安装目录里；
   新桌面与卸载/重装都未中断它，桌面**附着**到同一 pid/port。这与「一个数据根一个服务、客户端从不杀服务」一致，
   但也说明：**更新不会停掉在途服务**——W-16 票面要求的「运行中更新安全暂停（列在途 Task/客户端 → 安全暂停 → Ledger 结清，失败则中止替换）」
   没有被这次烟测覆盖，因为本次没有在途任务。
2. **关闭窗口 = 隐藏到托盘**（`desktop/src/main.ts` 的 tray/quit 设计：×/Alt+F4 隐藏并首次提示，显式退出走托盘菜单且先检查桌面托管的任务）。
   因此本烟测的「退出」腿是**显式结束进程**（非产品退出路径）；托盘 → quit 的显式退出路径（含任务检查与确认）**未实测**，属本文件诚实缺口。
3. 安装耗时较大（全新 299 s / 就地更新 218 s，载荷 204 MB）；卸载 7–9 s。腿间等待按此设置。
