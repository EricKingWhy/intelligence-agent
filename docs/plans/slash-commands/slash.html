输入框 / 命令菜单
在 composer 行首或空格后输入 /，输入框正上方弹出内联菜单；继续打字过滤，↑↓ 导航，Enter 执行。全部为本地命令——直接调已有 API，不经过 agent，不污染对话。

与 Ctrl+K 的关系：Ctrl+K 是全局动作面板（中央浮层），/ 是 composer 内的会话快捷入口；同一动作两处可达，不打架。
执行语义：全部 local 型，直接调已有 API（/compact→context/compact，/plan→workflow-mode 切换，/goal→task 接口，/model→模型切换，/permission→权限预设，/export→会话导出）。
不做的：/file（输入框已有附件按钮，不重复）；/feedback（已砍）；自定义命令（Claude Code 的 .claude/commands/ 那套，二期再议）。
