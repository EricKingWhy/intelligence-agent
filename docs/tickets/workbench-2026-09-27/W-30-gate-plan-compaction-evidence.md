## 明确契约（增补判据，全部可执行）

1. **压缩接班后清单不丢**：触发至少一次真实压缩后，UI 与事件投影中的进度清单与压缩前逐字一致（重放验证）。
2. **约束不丢**：压缩前植入精确约束（参照 W-01 的 `不得删除 old_rows` + 精确 ID `R-042` 模式），压缩后模型后续行为仍遵守（以行为证据判定，不以摘要文本目测）。
3. **失败方案不重走**：任务中人为制造一次失败并记录失败方案 fact（含 source_event_id）；压缩后继续任务，模型不得重走该路径（以 tool call 序列/事件流判定）。
4. **UI 无丢项**：压缩触发瞬间 UI 清单无闪烁、无丢项（真实操作证据，接入 W-20 夹具）。
